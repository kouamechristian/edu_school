# Captures d'écran du centre d'aide

Déposez ici les captures illustrant les guides du centre d'aide (`/support`).

## Convention de nommage

Chaque guide attend un fichier PNG précis, `<module>-<n>.png` :

| Module (`/support/<slug>`) | Fichiers attendus |
|-----------------------------|-------------------|
| `eleves`            | `eleves-1.png`, `eleves-2.png`, `eleves-3.png` |
| `notes`             | `notes-1.png`, `notes-2.png`, `notes-3.png` |
| `finances`          | `finances-1.png`, `finances-2.png`, `finances-3.png` |
| `recouvrement`      | `recouvrement-1.png`, `recouvrement-2.png` |
| `paiement-en-ligne` | `paiement-en-ligne-1.png`, `paiement-en-ligne-2.png` |
| `rh-paie`           | `rh-paie-1.png` |
| `absences`          | `absences-1.png` |
| `espaces`           | `espaces-1.png` |

## Fonctionnement

- Tant qu'un fichier est absent, le guide affiche un **emplacement réservé**
  indiquant le nom attendu. Aucune erreur, aucune modification de code.
- Dès que le PNG est déposé, la capture s'affiche automatiquement, avec
  agrandissement au clic.

## Conseils

- Format **PNG**, largeur ~1200 px, interface en thème clair pour la lisibilité.
- **Masquez les données personnelles réelles** (noms, téléphones, montants
  sensibles) : ces pages sont publiques.
